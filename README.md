O projeto "BixoQuest" consiste na implementação de um jogo RPG de simulação universitária, desenvolvido em Java com arquitetura MVC. O sistema simula a vida acadêmica de um estudante calouro de Engenharia de Computação da UEFS, desde a matrícula até a formatura. O jogador gerencia atributos como energia, saúde, dinheiro, motivação e conhecimento, tomando decisões que impactam seu desempenho acadêmico ao longo dos semestres. O jogo conta com eventos aleatórios, quests, interações com NPCs e persistência de dados em formato JSON, permitindo salvar e carregar múltiplos jogos simultaneamente. O trabalho foi realizado pelo discente Nícolas Carvalho Pimentel como requisito para a disciplina EXA863 - MI Programação, do curso de Engenharia de Computação da Universidade Estadual de Feira de Santana (UEFS), sob orientação da tutora Bianca Leite Santana.
